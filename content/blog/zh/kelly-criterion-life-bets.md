我们都听过“逆风翻盘”的故事。

马云被拒绝30次才拿到融资。J.K.罗琳被12家出版社退稿后才出版了哈利波特。乔布斯被自己创立的公司开除，又杀回来做出了iPhone。

这些故事听多了，你可能会觉得：**成功就是要敢赌、敢all in、敢梭哈。** 在最绝望的时候把一切都押上去，然后逆风翻盘，走上人生巅峰。

但你有没有想过一个问题：这些故事之所以被反复讲述，恰恰是因为它们**极其罕见**。你听过马云的故事，但你没听过那些同样梭哈了却血本无归的千万人的故事，因为没有人会去写一个失败者的传记。

而且更关键的是，**这些"逆风翻盘"的主角，其实根本没有在梭哈。**

马云在创办阿里巴巴之前，已经创业了3次，每次都是小成本试水。他一直保留着杭州师范的教师身份作为退路。罗琳在等出版结果的同时，主动去考了教师资格证，她没有把所有赌注压在哈利波特上。而乔布斯被赶出苹果的时候，口袋里装着1亿美元现金，他后来在Pixar上投的5000万也是分10年逐步投入的。

这些所谓的"梭哈英雄"，每一个都给自己留了后路。**他们的成功不是因为"敢赌"，而是因为他们知道每次该赌多少。**

今天我想讲一个数学上可以证明的事实："梭哈"不仅会让你在逆风局里失败，甚至会让你在顺风局里破产。而教会你"该赌多少"的，是一个叫**凯利公式**的东西。

## 一个你"必胜"的赌局

假设有人给你这样一个机会：掷骰子，大（4-6）你赢3倍，小（1-3）你输光。你手上有100块，可以重复玩很多次。

先做一个小测试：**你觉得每次应该下注多少？**

A. 每次梭哈100%

B. 每次下注50%

C. 每次下注33%

D. 每次下注10%

记住你的答案。

算一下期望：赢了拿300（期望300×50%=150），输了亏100（期望-100×50%=-50），净期望+100。这个赌局对你有利，是一个"顺风局"。

![](/blog/kelly-criterion-life-bets/fig-01.jpg)

如果只看单次收益，选项“A. 梭哈100%”是期望最大化的选择。但是——

## 8个平行宇宙里，7个你破产了

如果你连玩3次，每次梭哈，一共有8种同等概率的结果：

1. 大-大-大：100 → 400 → 1600 → **6400元！**
2. 大-大-小：100 → 400 → 1600 → **0元** 💀
3. 大-小-大：100 → 400 → 0 → **0元** 💀
4. 小-大-大：100 → 0 → 0 → **0元** 💀
5. 大-小-小：100 → 400 → 0 → **0元** 💀
6. 小-大-小：100 → 0 → 0 → **0元** 💀
7. 小-小-大：100 → 0 → 0 → **0元** 💀
8. 小-小-小：100 → 0 → 0 → **0元** 💀

8个平行宇宙里的你，7个都破产了。平均收益虽然有800元，但那只是因为一个幸运儿赚了6400把平均数拉上去的。其余7个你，一分钱都没有。

![](/blog/kelly-criterion-life-bets/fig-02.jpg)

**在一个明明对你有利的顺风局里，梭哈让你有87.5%的概率一无所有。**

这就是真相，不是逆风翻盘，而是**顺风破产**。

梭哈赢了，那叫传奇；梭哈输了，那只是沉默的大多数。而数学告诉你：沉默的大多数，占了87.5%。

## 正确答案是C——凯利公式

最佳策略是每次只押三分之一。这来自投资圈 赌博圈 大名鼎鼎的**凯利公式(Kelly Criteria)**。

你下注的33%赢了翻3倍变成100%，加上没下注的67%，总资产翻倍。输了只亏33%，还剩67%。

原来的8个平行宇宙会变成这样：

1. 大-大-大：100 → 200 → 400 → **800元**
2. 大-大-小：100 → 200 → 400 → **267元**
3. 大-小-大：100 → 200 → 133 → **267元**
4. 小-大-大：100 → 67 → 133 → **267元**
5. 大-小-小：100 → 200 → 133 → **89元**
6. 小-大-小：100 → 67 → 133 → **89元**
7. 小-小-大：100 → 67 → 44 → **89元**
8. 小-小-小：→ **30元**

最差也还有30块。最好翻了8倍。**没有任何一个宇宙里你破产了。**

你放弃了64倍的暴富幻想，换来了一件更珍贵的东西：**你在每一个宇宙里都还活着。**

凯利公式的具体计算：全押的期望净收益率（100%）÷ 赢的收益（300%）= 最优下注比例（33%）。最反直觉的部分是“除以300%”：**赢面越大的局，你越要少押。** 能翻几倍，就用几分之一去赌。这样你才能扛过运气差的时候，等到胜利。

## 凯利公式不仅在赌场里，它还在你的每一个人生选择里

你可能觉得这只是一个数学游戏。但如果我换一种说法，你可能会觉得它就在你身边：

**凯利公式的本质，就是"试错资源分配"。** 你有多少本钱（时间、金钱、精力），你要分配多少在这次尝试上。分配太多，一次失败你就出局了；分配太少，你可能永远等不到回报。凯利公式帮你找到那个最优的比例。

**投资：你的仓位就是你的"试错预算"。** 你看好一只股票，判断60%的概率涨50%、40%的概率跌40%。套公式：(60%×50% - 40%×40%) ÷ 50% = 28%。哪怕你很看好，最多拿三成资金去买。2015年股灾里加杠杆全仓的人，很多在一个本来长期向上的市场里，永远退出了牌桌。巴菲特从来不会看好一家公司就把全部身家押上去，从而不会一两次错误判断而破产。

**创业：你的预算就是你的"试错额度"。** 马云在创办阿里巴巴之前，先做了海博翻译社、中国黄页，还在外经贸部积累了人脉。每一次都是小赌注，每一次都在学习。如果他1994年就辞职梭哈，可能今天就没有阿里巴巴了。硅谷"Fail fast, fail cheap"的本质就是：**把失败的成本控制在你能承受的范围内，这样你才能失败足够多次，直到成功。**

**跳槽：你的稳定性就是你的"安全垫"。** 薪资翻倍但前景不明？先用20%的业余时间去接触那个行业，参加行业活动、做side project、跟圈内人聊。验证靠谱了再加大投入。裸辞是梭哈，骑驴找马是凯利。你以为的"犹豫不决"，其实可能是最优策略。

**考研：你的时间就是你的本金。** 不确定能不能考上？一边考研一边投简历。万一没上岸，还有offer兜底。罗琳在等哈利波特出版结果的同时，去考了教师资格证。**这不是"脚踏两只船"，这是给自己留活路。** 而数学证明了：留活路的人，最终走得最远。

## 你的"人生下注比例"是多少？

问自己三个问题：

1. **你现在最大的一个"赌注"是什么？** 考研、跳槽、创业、一笔投资？

2. **如果这个赌注失败了，你还剩多少"本金"可以重新来过？** 如果答案是"几乎没有"，你可能在梭哈。

3. **你有没有Plan B？** 罗琳有教师资格证，马云有教师职业可以回去，乔布斯有1亿美元现金。你的Plan B是什么？

如果你发现自己正在梭哈，别慌，不需要放弃你的目标，只需要调整你的下注比例。

## 对抗"梭哈叙事"

当然，现实不像赌场，概率往往是猜的。你觉得50%的成功率，实际上可能只有10%。所以很多聪明人用**"半凯利"**：只押公式建议的一半，给未知风险留余量。

但我觉得凯利公式最深刻的意义，不在于计算本身，而在于它戳破了一种流行的幻觉。

我们的朋友圈、短视频、新闻头条里充斥着"梭哈成功"的故事。每一个all in赢了的案例都被放大一万倍传播，让你觉得勇气就是一切、犹豫就是失败。但当你真的去挖掘那些"梭哈英雄"的故事，你会发现他们每一个人都给自己留了后路。马云有教师职业可以回去，罗琳考了教师资格证，乔布斯带走了1亿美元现金。

**他们不是在梭哈。他们是在用凯利公式。**

而数字不撒谎，**顺风局梭哈都有87.5%的破产率，何况人生中大部分局面连顺风都算不上。**

下次你又被一个"逆风翻盘"的故事热血上头的时候，记得问自己：

**那7个破产的平行宇宙里的人，他们的故事为什么没人讲？**

你不需要成为那个传奇。你只需要确保自己在赢之前，还在牌桌上。
